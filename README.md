# Yule Synth Snowflake

https://github.com/bansheegalileo/hhs-yule_synth_snowflake/

![Screenshot 2025-04-15 114416](https://github.com/user-attachments/assets/10c79ac9-7092-4b68-be33-57731842efea)


The Yule Synth Snowflake is a web-based synthesizer toy using samples of the LIRA 8 Russian synthesizer to capture the harsher, dangerous side of the wintertime in frigid atonal drones. Winter can be a time for joy, for holidays, to stay inside- but what if you have no choice but to be outside? What if you're faced with the elements with no barrier, no way to warm yourself? Then, it is a terror of a season indeed. It was developed using HTML and CSS, using JavaScript to implement the functionality to play its associated sounds. It was developed for the hack sprint at the then Holberton school by myself, and launched at the end of the project date. 

The development of the Yule Synth Snowflake was on a short time scale, and I was not able to implement all of the features I had planned for. Originally, there were plans for a variety of different sounds to add to the soundscape. There were plans for rhythmic loops tied to an Arctic fox and hare, mimicing their footfalls in the snow. Therewere plans for shorter sounds tied to a representation of icycles, comparable to a glockenspeil. There were plans for keyboard compatibility, where the keyboard could be used to trigger different elements on the page- the page acting as a kind of toy instrument. The project deadline closed before then, and I moved on from it to work on newer assignments without returning to it.

To interact with the synth snowflake, simply visit https://bansheegalileo.github.io/hhs-yule_synth_snowflake/ and click on the branches of the snowflake.
